# Wanderly — Travel Booking Landing Page

A fictional travel booking service designed for the IPS UI/UX Figma assignment. Wanderly helps students, young professionals, families, and travel enthusiasts explore destinations and plan memorable trips.

## Deliverables
- `Wanderly_Desktop_1440.png` — full desktop screenshot (1440 × 2520)
- `Wanderly_Mobile_390.png` — full mobile screenshot (390 × 2940)
- Corresponding editable vector `.svg` files for importing into Figma
- `FIGMA_GUIDE.md` — instructions for reconstructing native Auto Layout and components

## Design decisions
- **Palette:** Ocean teal `#007F82`, dark navy `#102334`, pale aqua `#D9F3F0`, white `#FFFFFF`
- **Typography:** Arial in supplied SVGs; use Inter or Poppins when rebuilding in Figma
- **Audience:** Leisure travelers, students, families, and young professionals
- **Hierarchy:** Clear hero messaging, prominent booking form, destination cards, benefit cards, and conversion CTA
- **Responsive design:** Four-column destination grid on desktop and two-column grid on mobile; stacked booking fields on mobile

## Import into Figma
1. Create a new Figma Design file.
2. Drag in both SVG files. SVGs contain editable vector and text elements, but **do not automatically contain native Auto Layout or reusable Figma components**.
3. Follow `FIGMA_GUIDE.md` to rebuild semantic frames and components with Auto Layout.
4. Share your Figma file and GitHub repository link for the IPS submission.

## Note
This is a visual design concept, not a functional booking engine. Destinations and prices are illustrative only.
